# Welcome

DjangoCloud deploys your Django project to your own AWS account with one command. You skip the Dockerfiles, load balancers and server setup, and keep every release saved so you can roll back.

```bash
pip install djangocloud-cli
python manage.py djangocloud login
python manage.py djangocloud deploy
```
